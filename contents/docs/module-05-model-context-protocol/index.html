What is Model Context Protocol?

Place MCP at the integration layer before using an SDK.

Core idea

MCP is an open protocol that lets an AI host discover and use selected tools, resources, and prompts from external servers through a consistent client–server interface.

What MCP is

A standard integration boundary. A server wraps a bounded capability; a client connects, discovers it, and makes it available to the host application.

What MCP is not

It is not an LLM, an agent framework, a permission system by itself, or a guarantee that a tool is safe to execute.

Why this matters

Without a shared protocol, each host must learn a different integration contract for every filesystem, repository, database, or business API. MCP makes capability discovery and invocation more consistent; application policy still decides what may be exposed and executed.

AI host
  └─ MCP client ── standard protocol ── MCP server ── selected external system

Production principle

MCP standardises connectivity. Your application still owns identity, consent, authorisation, validation, execution policy, isolation, auditing, and budgets.
